## Foodieland

Каталог рецептов

### [Ссылка на проект](https://lizaelkina.github.io/foodieland-markup 'Выполненный проект')

### [Ссылка на макет в Figma](https://www.figma.com/design/InOc1w55wrt9qqZQB4JA86/Foodieland?node-id=1-296&p=f&t=e2TowIXDMtgdd4g2-0 'Макет в Figma')

### Описание проекта

- Многостраничный, адаптивный сайт на Flexbox и Grid Layout.
- Библиотека "Swiper" для слайдеров.
- Интерактивные карточки рецептов.
- Форма обратной связи.
- Видео-рецепты.

### Используемые технологии

- PUG
- SCSS
- JavaScript
- GULP
- Webpack
- Swiper
